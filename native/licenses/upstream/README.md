# Supplemental upstream licenses

These files cover target-shipped crates whose archives omit license documents.

- `dasp_sample` uses RustAudio's MIT license at commit `d0892971a3b72dee9b3ff0d16f94b0962605e858`.
- `realfft` declares MIT at tag `v3.5.0`, commit `d0d4eee0525fd27c96c8a046d6d107acd5ed84a6`.
- `realfft` identifies HEnquist as its author but provides no separate license file.
- Its supplemental file combines that upstream declaration with the complete MIT text.

The generator includes only macOS ARM64 and Windows x64 runtime dependencies.
